# Wallpapers

One folder per theme name (`kanagawa/`, `tokyo-night/`, `gruvbox/` …), matching the
names `dot theme` knows. `dot theme <name>` picks a random image from the matching
folder; `dot wallpaper` re-rolls within the current theme.

Images are not committed here yet — drop your own in, or use Noctalia's Wallhaven
panel (`Super+Shift+W`) to find some. Suggested searches for Kanagawa: "The Great Wave",
"ukiyo-e", "sumi-e mountains", "kanagawa wave dark". Keep files under ~5 MB and
name them `<slug>.jpg`; git LFS is not set up, so prefer a handful of good ones.
